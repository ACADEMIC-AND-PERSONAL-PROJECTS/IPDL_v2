# Product Backlog - SenSante Pro

Ce backlog regroupe les 8 User Stories du projet SenSante Pro, d'apres le plan de cours IPDL2.

| ID | User Story | Sprint | Statut |
|---|---|---|---|
| US-01 | En tant qu'agent de sante, je veux m'authentifier afin d'acceder a la plateforme de facon securisee. | 1 | Done |
| US-02 | En tant qu'agent de sante, je veux enregistrer un patient afin de creer son dossier medical. | 1 | In Progress |
| US-03 | En tant qu'agent de sante, je veux creer une consultation afin de saisir les symptomes d'un patient. | 1-2 | To Do |
| US-04 | En tant que medecin, je veux obtenir une analyse IA des symptomes afin d'orienter mon diagnostic. | 2 | To Do |
| US-05 | En tant qu'agent de sante, je veux naviguer dans une interface web afin d'acceder rapidement aux donnees. | 2 | To Do |
| US-06 | En tant qu'administrateur, je veux consulter les statistiques afin de suivre l'activite. | 3 | To Do |
| US-07 | En tant que DevOps, je veux un pipeline CI/CD automatise afin de garantir la qualite a chaque commit. | 3 | To Do |
| US-08 | En tant qu'administrateur, je veux consulter les logs d'audit afin de tracer les actions sensibles. | 4 | To Do |
